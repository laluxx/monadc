[DEC id:dec.web-html.safe-values-2026-07-28 by:human src:user-request conf:high]
  HTML is an ordinary typed core value and an indentation-owned embedded
  language. Text and attribute values escape HTML syntax by default; trusted
  raw markup requires the explicit =raw-html= constructor.
