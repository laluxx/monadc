Monad needs one semantic IR whose purpose is to make the unified typing,
effect, quantitative, ownership, and staging judgments authoritative before
lowering to optimization SSA or LLVM. It must replace overlapping handoffs;
adding it as another parallel interpretation would be failure.

[DEC id:dec.ir.semantic-ir-first-2026-07-30 src:user-request,qtt/README.org conf:high]
  Design a small typed, block-structured Semantic IR before considering MLIR.
  MLIR may later host lower dialects, but it cannot decide Monad's type theory,
  resource semantics, closure evidence, or proof boundary.

* Judgment and node contract

Each accepted function carries a checked instance of:

  =Σ ; Ψ ; Ξ | Γ ⊢ℓ e ⇑ A ! ε ▷ Δ ⊣ C=

Every node preserves canonical =TypeId=, lexical =BinderId=, qualified closure
and instance provenance, explicitly labelled construction/latent/domain/call
grades, effect rows, ownership capabilities, physical representation,
region/scope identity, and a stable evidence reference.

Control flow uses explicit blocks, parameters, terminators, and joins. Branch
joins carry both value types and resource states. Exceptional and handler exits
are first-class cleanup edges rather than backend accidents.

* Compiler layering

1. Surface AST and reader expansion.
2. HM/dependent elaboration producing canonical types, effects, and grades.
3. *Semantic IR*: the sole authority for accepted resource semantics.
4. Ownership/cleanup lowering, validated by simulation against Semantic IR.
5. Optimization SSA and LLVM.

Typed Core, source-grade traversal, QTT ANF, and Resource IR are migration
inputs. Each must become a producer, verifier, or lowering of Semantic IR—or
be deleted. None remains an independent authority afterward.

* Initial instruction families

- values: literal, global, parameter, constructor, projection;
- binding: graded =let= with separate evaluation effect and alias demand;
- closure: construction with typed environment slots and latent signature;
- call: direct, signature-known indirect, closure-instance, and FFI contract;
- control: branch, join, return, effect raise/handle, unreachable;
- resources: borrow, move-out, identity-preserving rehome, duplicate, drop,
  region enter/exit;
- staging: quote/splice only after layered typing is established.

* Migration gates

1. [-] Write the C data model and a smaller independent verifier. The first
   structural slice is =qtt/semantic_ir.[ch]=: deterministic flat nodes,
   subtree boundaries, source identity, binder provenance, and owned symbolic
   evidence are verified. Canonical =TypeId=s and grade-role classifications
   are now mandatory. Per-node quantitative payloads, pure effect rows, and
   direct closure/call identities are now checked. Physical representation and
   resource capability are separate checked fields; heap representation is
   conservatively =unknown= capability until ownership inference supplies a
   proof. Inferred non-empty effects, interprocedural closure contracts, and
   general resource-state transitions remain. The lexical first-order fragment
   now carries a checked cleanup plan owned by the Semantic-IR function.
2. [-] Lower the coherent pure fragment and differentially compare types,
   grades, effects, and evaluation. Quantitative coherence now reads verified
   Semantic-IR evidence directly; type/effect/evaluation comparison remains.
3. [ ] Import correlated HM call evidence for indirect calls.
4. [-] Lower closure environments and cleanup edges. Semantic IR now owns
   canonical static closure-field records and checks physical-plan
   correspondence. ANF now materializes a certified dense environment-slot
   interface and verifies explicit field projections. Straight-line unique
   closure bodies automatically produce borrow/move/release projections,
   including nested conditional joins, mixed move/release fields, and typed
   immediate/inline lexical lets and signature-known SSA calls;
   capture-consuming calls, ownership-bearing lets, shared fields, and
   aggregate-field transfers remain.
5. [ ] Make ownership ANF consume Semantic IR rather than typed Core.
6. [ ] Delete superseded paths only after differential coverage.
7. [ ] Consider an MLIR dialect only after this contract is stable.

The verifier rejects missing evidence, identity collisions, malformed joins,
grade mismatches, effect erasure, and ownership-state divergence.
