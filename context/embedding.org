[DEC id:dec.embedding.two-lane-api date:2026-08-14 by:human+llm]
  Monad embedding has two complementary call paths. The stable dynamic path
  uses opaque handles, checked statuses, and versioned structures. The native
  path exposes signature-checked function pointers for supported closed ABI
  types. Dynamic convenience must not impose boxing on a native typed call.

[DEC id:dec.embedding.no-internal-abi date:2026-08-14 by:human+llm]
  =RuntimeValue=, LLVM objects, compiler environments, and =.mexp= structures
  are implementation details. They must not appear in the installed embedding
  header. Public symbols are real =monad_*= functions with hidden visibility
  as the library default; ABI evolution uses size/version fields.

[DEC id:dec.embedding-protected-boundary date:2026-08-14 by:human+llm]
  No language failure may abort, exit, or longjmp across a C host boundary.
  Embedding operations return =monad_status_t= and optionally populate a
  structured error. Error message storage is library-owned and remains valid
  for the duration documented by the operation family.

[DEC id:dec.embedding-thread-attachment date:2026-08-14 by:human+llm]
  Calls that can enter Monad execute through an explicit thread attachment.
  Attachments are thread-affine and keep their runtime busy until detached.
  Runtime creation/destruction is a host lifecycle operation and must not race
  calls using that runtime.

[OBS id:obs.embedding-lifecycle-slice src:embed/include/monad/embed.h,embed/embed.c conf:high]
  ABI version 1 implements opaque runtime/thread handles, version negotiation,
  allocator injection, explicit attachment, thread-affinity checking,
  deterministic busy destruction, and a hidden-by-default shared library.

[OBS id:obs.embedding-native-pointer-slice src:embed/include/monad/embed.h,embed/embed.c,tests/embedding/branches/native-call/atom.embedding.02.native-call.zero-wrapper/host.c conf:high]
  Cycle 2's first executable slice binds an in-memory versioned module
  descriptor, checks artifact and signature fingerprints once, retains module
  lifetime with a function token, and returns the descriptor's exact function
  address. The host calls that address directly; no embedding dispatcher or
  wrapper executes on the hot path.

[DEC id:dec.embedding.performance-contract date:2026-08-14 by:human src:user-request]
  The primary embedding performance goal is parity with hand-written C.
  Native lookup may validate and retain state, but repeated calls must not box,
  allocate, dispatch by signature, reflect, or cross a wrapper trampoline.
  Claims of parity require pointer/assembly evidence and representative
  benchmarks against an equivalent C function.

[DEC id:dec.embedding-dry-contract date:2026-08-14 by:human src:user-request]
  Embedding APIs must avoid ceremonial wrappers and duplicate representations.
  One canonical descriptor and one lifecycle model serve static, dynamic, and
  future ORC-backed loading. Additional handles are justified only when they
  carry necessary ownership, synchronization, or unload-safety state.

* Certified module boundary

[OBS id:obs.embedding-mqti-boundary src:qtt/interface.h,qtt/README.org conf:high]
  =.mqti= version 12 stores callable ownership/effect contracts and an object
  content fingerprint. Its supported ownership interface is restricted to
  closed flat types. A mismatched object fingerprint must fail closed for
  certified ownership decisions.

[DEC id:dec.embedding-certified-fast-path date:2026-08-14 by:human+llm]
  Native entrypoint lookup will require a supported portable ABI signature, a
  matching object/interface fingerprint, and an embedding ABI descriptor.
  The existing callable contract alone is not a complete C calling convention
  and must not be treated as one.

[DEC id:dec.embedding.structural-abi-compatibility date:2026-08-14 by:human+llm]
  Native-call authority is structural equality in the versioned signature
  algebra, including calling convention, result, arity, and every ordered
  parameter type. Fingerprints may index or accelerate this relation but can
  never replace it. This makes hash collisions irrelevant to type safety and
  rejects LLVM caller/callee prototype mismatch before returning an address.

[OBS id:obs.embedding.abi-algebra-v1 src:embed/include/monad/embed.h,embed/embed.c,embed/README.org conf:high]
  Native ABI v1 is the closed finite algebra of fixed-width integers and
  IEEE-754 =f32/f64= parameters, with those atoms plus =void= as results and C
  as the sole calling convention. Managed pointers, aggregates, variadics, and
  target-dependent C integer spellings are omitted rather than approximated.

[DEC id:dec.embedding.bidirectional-native-symmetry date:2026-08-14 by:human src:user-request]
  Native embedding is bidirectional: C hosts call Monad exports and compiled
  Monad calls runtime-registered C imports. Both directions use the same
  structural ABI algebra, resolve once, and call the exact address without a
  dynamic-value wrapper.

[OBS id:obs.embedding.host-native-registry src:embed/include/monad/embed.h,embed/embed.c,tests/embedding/branches/bidirectional/atom.embedding.03.bidirectional.zero-wrapper/host.c conf:high]

[DEC id:dec.embedding.live-image date:2026-08-14 by:human src:user-request]
  Embedding targets a Lisp-like live image for a Vulkan-based Emacs rewrite:
  functions and variables can be redefined at runtime, and C tooling can query
  all bindings, documentation, types, and type-filtered inventories.

[DEC id:dec.embedding.live-vs-frozen date:2026-08-14 by:human+llm]
  Frozen pointers provide the minimum direct C ABI cost and intentionally do
  not observe redefinition. Live bindings preserve identity and observe atomic
  replacement through one address-cell load. The API makes this choice explicit
  so render-loop code is never silently charged for editability.

[DEC id:dec.embedding.immutable-inventory date:2026-08-14 by:human+llm]
  Editor reflection consumes immutable, self-owning snapshots rather than
  pointers into mutable compiler/runtime tables. Snapshots are deterministic,
  filterable, safe across later mutation, and require no runtime lock while the
  editor renders or searches them.

  Epoch interference retries rather than exposing a torn inventory. The slab
  owns strings, documentation, ABI signatures, parameter arrays, values, types,

[DEC id:dec.embedding.foreign-object-nominality date:2026-08-14 by:human+llm]
  Host-defined foreign types are generative and nominal. Payload projection
  requires exact type-handle identity; equal C layouts never authorize access.
  Successful object creation transfers payload ownership, final release invokes
  the type destructor synchronously exactly once, and a live object prevents
  unregistering its type.

[DEC id:dec.embedding.foreign-ownership-alignment date:2026-08-14 by:human+llm]

  than treating binder quantity as alias authority. Unique foreign objects
  reject retain; shared foreign objects permit it. Borrowed foreign objects are
  withheld until the public ABI can carry a checked region/loan token.

[DEC id:dec.embedding-end-state date:2026-08-14 by:human+llm]
  Embedding is complete when a C host can create isolated runtimes; compile
  source or load certified precompiled modules; inspect diagnostics, inferred
  environments, effects, and QTT ownership evidence; invoke dynamic values or
  validated native entrypoints; exchange owned and borrowed data under explicit
  contracts; register callbacks safely; run concurrently; unload deterministically;
  and recover from every language/compiler failure without process termination.
  The installed ABI must remain compatible across a declared stable release
  series, work from C and C++, and require neither compiler internals nor LLVM
  for runtime-only deployment.

* Research basis

[DOC id:doc.embedding-research-basis src:external-primary-docs conf:high]
  The architecture is informed by Guile's explicit VM-entry boundary and
  stable API policy, Lua's state/protected-call discipline, CPython's opaque
  stable ABI and explicit thread attachment, and Julia's distinction between
  boxed generic calls and native =@cfunction= pointers. These are design
  inputs, not claims of binary compatibility.

[DEC id:dec.embedding-orc-resource-tracking date:2026-08-14 by:human+llm]
  When source/JIT embedding arrives, one loaded Monad module maps to an LLVM
  ORC resource tracker rather than leaking symbols into a process-global JIT
  namespace. Lookup must use target data-layout mangling, initialization must
  be explicit, and unload must fail while host-visible functions or values
  retain the module. LLVM's LLJIT C API itself is experimental, so it remains
  behind Monad's stable ABI and is never exposed from =embed.h=.

[DEC id:dec.embedding.native-generation-commit date:2026-08-15 by:human+llm]
  Source publication stages code and all registration metadata before entering
  one runtime critical section. The commit validates the complete export set,
  changes every registry cell, and advances the binding epoch exactly once, or
  changes nothing. Resolution and immutable snapshots therefore observe one
  registry generation. Already-retained live cells remain individually atomic;
  coherence across several independent hot calls requires a future explicit
  read-generation token and is not falsely claimed by the zero-wrapper API.
