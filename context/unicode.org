* Priority

  Replace the minimal =Text.Unicode= boundary with a complete, data-driven,
  versioned Unicode core module.  This is the first priority after the current
  first-order modal logic and Wisp-reader cycle.

* Required scope

- Unicode scalar-value decoding and validation with explicit error policies.
- Extended grapheme-cluster segmentation (Unicode Standard Annex #29).
- Canonical and compatibility normalization: NFC, NFD, NFKC, and NFKD
  (Unicode Standard Annex #15).
- General categories, scripts, blocks, binary properties, and property lookup.
- Locale-independent default case conversion and full case folding, including
  multi-code-point mappings.
- Word, sentence, and line-boundary algorithms (UAX #29 and UAX #14).
- Terminal column width based on grapheme clusters, combining marks, emoji
  sequences, variation selectors, and East Asian Width (UAX #11).
- A generated Unicode Character Database with a pinned Unicode version,
  reproducible update tooling, conformance fixtures, and property tests.
- Clear distinctions among byte length, scalar count, grapheme count, and
  terminal display width; none may be exposed under an ambiguous =length= API.

* Current boundary

[OBS id:obs.unicode.core-text-foundation src:core/Text/Unicode.mon conf:high]
  =Text.Unicode= now owns UTF-8 scalar decoding, scalar counting, grapheme
  counting, and cluster-based terminal width in Monad source. The grapheme
  state machine explicitly covers UAX #29 GB3, GB6–GB8, GB9/GB9a-style
  extending behavior used by the current property layer, and GB12/GB13
  regional-indicator parity. Imported-module regression tests cover CRLF,
  decomposed Hangul, flag pairs, and an unpaired third regional indicator.

[FIX id:fix.unicode.unsigned-byte-promotion date:2026-07-28 src:codegen.c conf:high]
  Hex octets infer as unsigned Byte values. Mixed-width comparisons, arithmetic,
  and function arguments now zero-extend Byte operands instead of sign-extending
  values at or above =0x80=. This fixes core-owned UTF-8 decoding without adding
  a Unicode runtime intrinsic.
