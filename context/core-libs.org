[DEC id:dec.text-parser.consumption-algebra-2026-08-11 date:2026-08-11 by:codex]
  The production parser API uses =ParseReply a= with explicit consumed versus
  empty success/failure. This follows Parsec's operational distinction: an
  alternative may run after an empty failure, while a consumed failure is
  committed unless the grammar explicitly requests backtracking. The first
  executable basis includes sequencing, explicit backtracking, explicit cuts,
  labels, EOF, reusable literals, and farthest-offset failure selection;
  compatibility =ParseResult= operations remain while existing first-order
  clients migrate.

[FIX id:fix.text-parser-char-ownership-2026-08-11 date:2026-08-11 by:codex]

  =Text.Parser= now imports =Data.Char=, converts raw integer bytes through
  =chr= at the boundary, composes =blank?= with =linebreak?= for the exact RFC
  8259 whitespace set, and uses =digit?= plus =digit->int= for numbers.

[FIX id:fix.text-parser-import-boundary-2026-08-11 date:2026-08-11 by:codex]
  Added =tests/parser_imported_reply_recursive_adt.mon= to prove that imported
  polymorphic =ParseReply= values remain valid beside recursive client ADTs.
  The earlier JSON failure was an inference-order interaction around overloaded
  =Data.Char= methods after a generic reply consumer, not an imported-ADT ABI
  failure. =Data.Char.byte-digit?= now provides a monomorphic byte seam, scalar

  consume =parser-literal= replies directly.

[DEC id:dec.text-parser-expectation-semilattice-2026-08-11 date:2026-08-11 by:codex]
  Parser expectations form a canonical finite join-semilattice. Expectations
  are maintained in stable code order; union is idempotent; farther failures
  dominate nearer failures; and equal-offset alternatives join their labeled
  expectations. This gives parser choice an associative diagnostic summary
  independent of incidental evaluation order.

[DEC id:dec.text-parser-reply-laws-2026-08-11 date:2026-08-11 by:codex]
  Consumption is the two-point join semilattice =False ⊑ True= and bind
  combines observations with =∨=. =attempt= and =cut= are idempotent
  projections to =False= and =True= on failure. Literal chunks automatically
  backtrack for ordered choice while retaining their furthest mismatch;
  labels rewrite only empty failures. Equal-offset failure codes use a
  canonical minimum while expectation sets join, so diagnostic choice is
  commutative and deterministic at a fixed source position. These laws are
  checked in =tests/core_text_parser_combinators.mon=.

[FIX id:fix.text-parser-pretty-diagnostics-2026-08-11 date:2026-08-11 by:codex]
  =render-parser-error= now renders a stable filename/line/column header,

[FIX id:fix.text-format-char-boundary-2026-08-11 date:2026-08-11 by:codex]
